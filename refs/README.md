# Reference photos (not included)

Put your own photos here, one per view, named by view: `ref_front.png`, `ref_three_quarter.png`, `ref_top.png`,
`ref_neck.png` (perfume). Product-page photos on a plain backdrop
work best; phone photos work too (see the playbook on busy backgrounds and known lenses).

Every script refers to views by these names; comparison sheets pair `ref_<view>` with `<prefix>_<view>`.
